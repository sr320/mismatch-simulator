Mismatch Simulator

The epigenetic trap, made explicit. When does anticipatory environmental memory stop paying for itself and start costing more than it returns? Framework Question 8, as a model you can push on.

This is a toy model. Its parameter ranges are anchored to real persistence measurements from the Conditioning Atlas (109 extracted experiments); its functional forms are assumptions chosen to be interpretable, not derived from marine invertebrate physiology and not fitted to any dataset. It exists to sharpen the question and generate testable predictions. No number it produces should appear in a manuscript as a result. See MODEL.md for the full specification and limitations.
