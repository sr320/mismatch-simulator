Model assumptions

This is a conceptual relative-fitness model, not an empirical forecast. Frontloaded organisms pay a constant preparedness cost. Reactive organisms respond accurately after a lag. Memory-primed organisms recover part of that lag only when retained cues still match the next stress event.

r = 2^(−P/H) memory retained between events q = (1−v)^P cue similarity at the next event threshold = first v where Wmemory ≤ max(Wfrontloaded, Wreactive)

Interpretation. A longer half-life raises the value of a stable cue but also preserves stale priming. Faster environmental turnover lowers cue similarity; it does not penalize the reactive strategy because that strategy observes the current condition.

The adjustable cost applies to inducible plasticity. The fixed coefficients are intentionally exposed in the page source so they can later be calibrated against a particular taxon, stressor, or experiment.

Reading the simulator

The chart is a compact way to reason about environmental memory across the timescales of stress recurrence, memory persistence, and environmental turnover. It is designed to generate testable questions—not estimate fitness for a particular species.

Environmental memory

Past experience can bias later responses through a multi-layer regulatory state that includes DNA methylation, gene-expression baselines, chromatin, and non-coding RNA. The state may persist within or across generations, but its stability and causal role differ by mechanism and system.126

Preparedness versus plasticity

Frontloading pays for preparedness continuously. Reactive plasticity avoids that standing cost, but can lose performance while the response is induced. Evidence from variable reef environments supports plasticity itself as a trait under selection, rather than a universally superior strategy.3

The epigenetic trap

Memory helps only while the next environment resembles the one encoded. If environmental turnover outpaces memory decay, retained priming can become a liability. This model exposes that crossover as a mismatch threshold and treats energetic cost as an adjustable uncertainty.15
